# Voca downloads

Free, on-device voice typing for macOS and Windows.

**[Download Voca](https://getvoca.vercel.app/download)** — choose your computer and the installer downloads directly. No account or subscription is needed.

This repository contains public installers, release notes, support, and notices. The application source is maintained privately.

## Install

- **macOS, Apple Silicon:** download `Voca-mac-arm64.dmg`.
- **macOS, Intel:** download `Voca-mac-x64.dmg`.
- **Windows 10/11, x64 (beta):** download `VocaSetup-windows-x64.exe`.

Installers are unsigned. See the [installation instructions](https://getvoca.vercel.app/download) and [security policy](SECURITY.md) before opening them. Each release includes `SHA256SUMS.txt` to verify your download.

On first launch, Voca downloads its speech model. Dictation then runs on your device.
